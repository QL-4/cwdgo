# 07 — 软件列表管理 UI

**What to build:** 设置窗口中管理 Software List：新增、编辑、删除应用（名称、可执行路径、启动参数）；变更持久化；面板打开时动作列表反映最新配置（序号随之更新）。

**Blocked by:** 05（设置窗口）

**Status:** ready-for-agent

- [ ] 设置中可新增软件（名称/路径/参数），必填校验（名称、路径非空）
- [ ] 可编辑已有条目、可删除条目
- [ ] 变更保存后持久化，重启后保留
- [ ] 面板中的动作序号与最新配置一致（删除后序号顺延、无空洞）
- [ ] 预置条目（PowerShell 等）与用户新增条目可区分，预置条目也可删除
